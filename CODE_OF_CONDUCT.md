# Code of Conduct

This project follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Everybody who takes part — in issues, pull requests, reviews or anywhere else
the project is discussed — is expected to follow it.

## Reporting

Report a violation to a maintainer listed in [MAINTAINERS.md](MAINTAINERS.md),
privately. If the report concerns a maintainer, or you would rather not go to
the project at all, the CNCF Code of Conduct Committee takes reports at
<conduct@cncf.io>.

Reports are handled in confidence, and nobody is penalised for making one in
good faith.
